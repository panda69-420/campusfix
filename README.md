# CampusFix

A web app where students report campus issues and track their status.
Built with Python, Flask, and SQLite.

## Setup
    python -m venv venv
    venv\Scripts\activate
    pip install -r requirements.txt
    python app.py

Open http://127.0.0.1:5000

## Default admin (development only)
Email: admin@campusfix.com
Password: set in `seed_data()` in app.py
